# Specs and safe zones (starting values, re-verify)
- Canvas: 1080x1920 (9:16), MP4, ~30fps. Source: ch-ad-creative/short-form-video-specs.md.
- Cross-platform safe band: keep clear top 220px, bottom 500px, left/right 180px. Centered text band = 720x1200 (y 220-1420). Numbers drift with app UI updates; check with each platform's overlay/preview.
- Captions: white fill, dark outline, static (no entrance animation), sized to fit the band.
- VERIFY per platform before stating: max duration, max file size, max upload resolution, supported frame rates.
