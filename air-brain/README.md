# AIR Brain

A small, curated set of Claude Code skills for AIR's marketing, lead-generation and video work. Start with [GUIDE.md](GUIDE.md).

- `skills/` - 12 skills (11 imported from open-source repos, 1 written for AIR)
- `CLAUDE.md` - routing rules Claude follows when this folder is loaded
- `sources.md` - where each skill came from, license, commit
- `overlap-map.md` - which skill to use vs. the plugins already installed
- `LICENSES/` - upstream license texts (MIT). Keep them with the skills.

Status: draft. No scripts are included; every skill is markdown only.
